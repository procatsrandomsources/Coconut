☕ How do i join the server? ▼
  1. Step 1: Open Multiplayer Menu

    From the main menu, go to Multiplayer and click Add Server at the bottom of the screen.

  2. Step 2: Enter Server Info

    Set the Server Name to Coconut and enter the main Server Address: play.coconutsmp.qzz.io. Click Done.

  3. Step 3: Alternative Server IP (If Main IP Fails)

  4. Step 4: Join the Server

    Select Coconut from your server list. Once the status turns green showing Coconut SMP - Chill Survival, click Join Server.

📱 How can i join on bedrock ▼
  1. Step 1: Open Social Menu

    From the Minecraft Bedrock main menu, click the Social / Friends icon in the top right corner.

  2. Step 2: Search for People

    Click on Search for people at the top of the side menu.

  3. Step 3: Gamertag Search Box

    Click the search box under Find players by gamertag.

  4. Step 4: Search "playcoconut"

    Type playcoconut into the search field and press Enter.

  5. Step 5: Add Friend

    Click Add Friend next to the playcoconut profile.

  6. Step 6: Join World

    Return to your Worlds tab. Look under LAN Worlds for Coconut SMP's world (Chill Survival) and click it to join!

🎨 How can i change my skin? ▼
  1. Step 1: Download a Skin

    Visit NameMC or your preferred skin repository, find a skin you like, and click the Download button.

  2. Step 2: Upload Skin to Discord

    Drag and drop your downloaded skin .png file into the #skins channel on the Coconut SMP Discord server.

  3. Step 3: Copy Image Link

    Right-click the uploaded skin image in Discord and click Copy Image Link.

  4. Step 4: Set Skin In-Game

    In-game, open chat and run /skin set <copied_url>.

  5. Step 5: Reset Skin or Verify

    To clear or reset your skin back to default at any time, run /skin clear. Your skin updates immediately for all players!
